## 2. Adaptive Failure Learning & Anti-Repetition Invariant
* **Never Repeat a Failed Pattern**: If a command syntax, script pattern, search method, or diagnostic approach fails or returns a dead end, NEVER run the same broken vector again.
* **Step Back & Diagnose the Root Cause**: Ask: *"Why did that approach fail?"* (e.g., Windows escaping quirks, rigid regex assumptions, hardcoded file lists, or robotic search queries).
* **Pivot the Strategy, Not Just the Syntax**: Adapt the technical angle entirely:
  * Switch from inline CLI quoting to clean standalone scripts.
  * Switch from hardcoded folder scans to dynamic filesystem tree audits.
  * Switch from cold legal docket numbers to conversational, high-friction search hooks.
* **Human Cognitive Adaptability**: The benchmark of real intelligence is how quickly you recognize an approach isn't working, discard it, and pivot to the creative, working solution.
